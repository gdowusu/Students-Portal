# Students Portal

A web based Students Portal application.

## Requirements

- Node.js 22.5 or newer
- npm

## Installation

1. Open the project folder:

   `students-portal`

2. Install the required dependencies:

   ```bash
   npm install
   ```

## Running the Application

Start the application using:

```bash
npm start
```

Open your browser and visit:

http://localhost:3000

## Database

This project uses Node.js built in SQLite support.

**Note:** Node.js 22.5 or newer is required for the built in SQLite functionality.
